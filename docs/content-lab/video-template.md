# Video Template

## Recommended Length

60–120 seconds for LinkedIn-native video.

Longer 8–12 minute versions can be embedded on GitHub Pages later, but short videos should be the default for reach.

## Structure

### 0–10 seconds

State the surprising observation.

### 10–30 seconds

Show the Copilot Ledger GUI and explain the session.

### 30–75 seconds

Zoom into the key measurement.

### 75–105 seconds

Explain what it means.

### 105–120 seconds

End with the practical takeaway.

## Video Style

- Screen recording
- Cursor zoom or visual highlighting
- Calm explanation
- No need for heavy production
- Focus on one insight per video
