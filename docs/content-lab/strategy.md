# Content Strategy

## Positioning

The project should be positioned as:

**Copilot Behavior Lab**

Tagline:

> Understanding how AI coding agents think, work, and spend credits.

Cost is important, but the broader topic is agent behavior.

## Primary Audience

- Developers using GitHub Copilot
- Architects
- GitHub customers
- Microsoft field teams
- GitHub field teams
- AI coding agent enthusiasts

## Primary Goal

LinkedIn attention and knowledge sharing.

GitHub Pages is the evidence layer, not the main publishing surface.

## Core Message

The biggest Copilot optimizations often come from helping the agent do the right work, not from blindly reducing tokens.

## Tone

Use a curious, evidence-based, non-confrontational tone.

Prefer:
- “In this session…”
- “The data suggests…”
- “This observation surprised me…”
- “This reinforces the official recommendation to…”

Avoid:
- “Microsoft is wrong”
- “GitHub guidance is wrong”
- “This always works”
- “This never works”

## Recommended Guidance to Reinforce

- Choose the right model for the right job
- Use Auto Mode where appropriate
- Provide useful context up front
- Avoid sending excessive context
- Be precise in prompts
- Set clear guardrails
- Review tools and skills periodically
