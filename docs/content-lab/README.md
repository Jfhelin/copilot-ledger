# Copilot Behavior Lab

This folder contains the content strategy, experiment notes, publishing plan and draft structure for a LinkedIn/GitHub Pages series about GitHub Copilot agent behavior and usage-based billing.

The goal is not to promote Copilot Ledger as a product.

The goal is to:
- Create strong LinkedIn content
- Spread accurate knowledge
- Explain how AI coding agents behave
- Show what actually drives cost
- Reinforce GitHub's official cost optimization guidance with concrete examples

Copilot Ledger is used as the analysis tool behind the observations.
