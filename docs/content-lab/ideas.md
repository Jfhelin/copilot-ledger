# Ideas

## Strong Observations

- The README was cheap. Finding it wasn't.
- I thought the answer was expensive. The plan was.
- Caveman Prompting barely moved the needle in a real coding-agent session.
- The most expensive token is the one the agent did not need to generate.
- Long sessions behave differently because context and cache dynamics change.
- Good context is not the same as more context.
- Precise prompts can reduce agent exploration.
- Tool calls are not bad, but each tool call often implies another model roundtrip.
