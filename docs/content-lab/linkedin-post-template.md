# LinkedIn Post Template

## Pattern

1. Surprising observation
2. Short session context
3. What the data showed
4. Why it matters
5. Practical takeaway
6. Link to evidence

## Draft Template

I thought [common assumption].

Then I analyzed a real GitHub Copilot session.

What surprised me:

- [finding 1]
- [finding 2]
- [finding 3]

The takeaway:

[practical guidance]

Full breakdown with measurements:
[GitHub Pages link]

## Style Notes

Keep the post short.

Avoid sounding like product marketing.

Use the tone of a curious engineer sharing a measurement.
