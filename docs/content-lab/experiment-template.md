# Experiment Template

This is the canonical structure for an experiment writeup. It matches the
"GitHub Pages Structure" in the `copilot-behavior-lab` skill, so a finished
experiment page and this template stay in sync.

# Title

## LinkedIn Hook

One surprising sentence.

Example:

> The README was cheap. Finding it wasn't.

## Executive Summary

2–4 sentences a reader can skim: what was measured and the single most
surprising takeaway.

## Hypothesis

What assumption are we testing?

## Why This Matters

Why should a developer care?

Short, direct conclusions.

## What Happened

Explain the agent flow.

Example:

1. User asked a question
2. Agent needed missing context
3. Backend requested a tool call
4. Tool result was added to context
5. A second model call produced the answer

## Interpretation

What does this mean?

## Practical Guidance

What should developers do instead?

## Confidence Level

High / Medium / Low — and why.
