Cost = `native_credits`, the **exact billed GitHub AI credits** (`total_nano_aiu`) per run.
Dollar figures = credits / 100. Source: 165 rows in
`~/copilot-ledger-data/captures/agents-md/evaluation/captures.jsonl`; regenerated by
`evaluation/scoring/consolidate.mjs`. n = BARE 10, AGENTS 10, **ORIG 3**, INIT 10 per task.

All numbers are **direct evidence** (measured, reproducible). Mechanism explanations are

---

## One-line thesis

The concise file made the **typical** run cheaper but the **average** run pricier — it shifted
cost onto the heavy build tasks. The repo's own verbose file was the **most expensive arm on
both measures**. The auto-generated file was **cheap** (mean = BARE, median ≈ AGENTS) despite
being ~5× the size — proving **file size does not drive cost, content does**. Honest cost
verdict: **"task-dependent, and *prose-y* text is what's not free,"** not "guidance saves money."

### Effort tracks cost (H3 support, Inference on causation)
On E3-debug, AGENTS cut mean requests **9.9 → 6.6** and tool calls **14.9 → 8.5** vs BARE — the
file pointed straight at the install/layout facts and the agent flailed less. On the heavy
code tasks the *prose* file (ORIG) raised effort most (E2 tool calls 36.9 → 44.0; E4 requests
30 → 41.7). **INIT, by contrast, kept effort at or below BARE on every task** (E2 tool 33.9 vs
36.9; E4 reqs 31.5 vs 30.0) — its accurate, structured context did not invite extra flailing
the way ORIG's prose did. **Inference:** *prose density*, not file presence or size, is what
inflates tool calls and runs.

## How to read it (candidate framings — pick, don't must-use)

- **"Pay for itself" is task-dependent.** The concise file earned back its ~129-token tax on
  navigation, debugging, and review (median ↓), but not on the two build tasks, where it
  correlated with more tool calls and longer runs at **no quality gain** (see
  [`quality-findings.md`](./quality-findings.md)).
- **Size doesn't drive cost — prose does.** ORIG and INIT are nearly identical token size
  (~650 vs ~641), yet ORIG is the **priciest** arm (mean 82.4, median 44.7) and INIT among the
  **cheapest** (mean 64.8, median 26.3). The difference is *what kind* of text: ORIG's verbose,
  opinionated prose inflated every turn; INIT's structured, repo-accurate file did not. "More
  tokens = more cost" is too coarse — replace it with "more *prose* = more cost."
- **Cheap is not the goal — value-per-credit is.** INIT is the cheapest arm on E1/E2 yet the
  lowest quality there. The concise AGENTS file is the only arm that is *both* cheap (typical)
  *and* quality-improving. Frame the cost story alongside quality, never alone.
- **Variance matters.** AGENTS slashed E5-review spread (sd 8.0 → 2.3) — more *predictable*
  cost even where the mean barely moved. INIT, by contrast, had E5 outliers (max 53.2) that
  re-widened the spread. Worth a callout.

## Caveats
- **ORIG cells are n=3 ⇒ directional only.** BARE / AGENTS / INIT cells are n=10. Per-task ORIG
  deltas are not significant without bootstrap CIs (registered as the next analysis step in the
  manifest). The robust cost claims are: (a) AGENTS median↓ / mean↑ split, (b) ORIG uniformly
  priciest, (c) INIT cheap-despite-large (size≠cost), all at n=10 except ORIG.
- **INIT had one E4 outlier-driven gate failure regime** — its mean (149.1) sits between BARE
  and AGENTS, but 3/10 INIT E4 runs failed the mechanical gate, so for INIT "cost per
  *successful* E4" is understated. (BARE/AGENTS/ORIG E4 gates were 10/10.)
- Otherwise cost-per-*successful*-task only; aside from the 3 INIT E4 gate fails, all runs
  passed their success gate, so no runs were excluded for cost.
- **The file itself costs credits to make.** Generating the INIT file via `copilot init` was a
  one-time **33.1 cr** — small, but non-zero, and worth noting against "auto-generate it free."
