> Supporting research for [`article-04-agents-md.md`](../../article-04-agents-md.md).
> This is a shared human/agent scratchpad, not published copy.

Cost = `native_credits`, the **exact billed GitHub AI credits** (`total_nano_aiu`) per run.
Dollar figures = credits / 100. Source: 115 rows in
`~/copilot-ledger-data/captures/agents-md/evaluation/captures.jsonl`; regenerated by
`evaluation/scoring/consolidate.mjs`. n = BARE 10, AGENTS 10, **ORIG 3** per task.

All numbers are **direct evidence** (measured, reproducible). Mechanism explanations are
labelled **Inference**.

---

## One-line thesis

The concise file made the **typical** run cheaper but the **average** run pricier — it shifted
cost onto the heavy build tasks. The repo's own verbose file was the **most expensive arm on
both measures**. So the honest cost verdict is **"task-dependent, and more text is not free,"**
not "guidance saves money."

**The mean/median divergence is the story for the concise file.** AGENTS pushed the *median*

expensive build runs got more expensive). **ORIG is highest on both** — it has no cheap regime.

### Effort tracks cost (H3 support, Inference on causation)
On E3-debug, AGENTS cut mean requests **9.9 → 6.6** and tool calls **14.9 → 8.5** vs BARE — the
file pointed straight at the install/layout facts and the agent flailed less. On the heavy
code tasks the files *raised* effort (E2 tool calls 36.9 → 42.7 → 44.0 across BARE/AGENTS/ORIG;
E4 requests 30 → 33.7 → 41.7). **Inference:** extra context invites the agent to do more, not
less, on open-ended build work.

## How to read it (candidate framings — pick, don't must-use)

- **"Pay for itself" is task-dependent.** The concise file earned back its ~129-token tax on
  navigation, debugging, and review (median ↓), but not on the two build tasks, where it
  correlated with more tool calls and longer runs at **no quality gain** (see
  [`quality-findings.md`](./quality-findings.md)).
- **More instructions are not free.** ORIG (~650 tok, ~5× AGENTS) is the priciest arm on mean
  *and* median, pricier than both others on 4/5 tasks. Every prompt pays for those input
  tokens every turn; the concise file captured the useful signal at ~1/5 the token cost.
- **Variance matters.** AGENTS slashed E5-review spread (sd 8.0 → 2.3) — more *predictable*
  cost even where the mean barely moved. Worth a callout.

## Caveats
- **ORIG cells are n=3 ⇒ directional only.** Per-task ORIG deltas are not significant without
  bootstrap CIs (registered as the next analysis step in the manifest). The robust cost claims
  are: (a) AGENTS median↓ / mean↑ split, (b) ORIG uniformly priciest.
- Cost-per-*successful*-task only; all 115 runs passed their success gate, so no runs were
  excluded for cost.
